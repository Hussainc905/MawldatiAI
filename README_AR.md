# مولدتي v0.5.0 — Dark Green + طباعة محلية + مساعد المولدة الذكي

هذه النسخة مبنية على v0.3.7 مع تغيير معماري أساسي:

- Supabase يُستخدم **فقط** للتحقق من ترخيص التطبيق وحالة التفعيل والانتهاء.
- لا يتم إرسال أسماء المشتركين أو أرقامهم أو الدفعات أو الوصولات أو الأمبيرات أو المبالغ إلى Supabase.
- جميع بيانات العمل محفوظة محليًا داخل الجهاز.
- عند تسجيل الدفع يُنشأ رقم وصل محلي تسلسلي بصيغة `ELY-YYYY-000001` ويحفظ الوصل في سجل محلي.
- يمكن إعادة طباعة الوصل من سجل الوصولات.
- الطباعة الحرارية تدعم:
  - Bluetooth Classic / SPP للطابعات المقترنة.
  - Wi-Fi / LAN عبر IP وPort (الافتراضي 9100).
  - عرض ورق 58mm أو 80mm.
- الوصل يُرسل للطابعة كصورة ESC/POS Raster لضمان ظهور العربية بشكل صحيح دون الاعتماد على خطوط الطابعة.
- النسخ الاحتياطي والاستعادة تتم عبر ملف JSON يختاره المستخدم من ذاكرة الهاتف/التابلت.
- ملف النسخة الاحتياطية يحتوي بيانات العمل المحلية وإعدادات الطابعة، لكنه **لا ينسخ رمز التفعيل أو بيانات الترخيص**.
- لا توجد أي وظيفة WhatsApp أو Supabase Receipts في هذه النسخة.

## قبل استخدام Bluetooth
قم بإقران الطابعة من إعدادات Android أولًا، ثم من داخل مولدتي:
الإعدادات → اختيار طابعة Bluetooth.

## طابعة Wi-Fi
يجب أن تكون الطابعة والهاتف/التابلت على شبكة تسمح بالاتصال بينهما. أدخل IP الطابعة وPort الخاص بـ RAW/ESC-POS، وغالبًا يكون 9100.

## GitHub Actions
المشروع يحتوي Workflow يقوم ببناء Debug APK باستخدام Java 17 وAndroid SDK 35.


## تحديث v0.4.1
- إضافة بحث داخل صفحة الجباية بالاسم أو الهاتف أو المنطقة.
- تحسين دعم أجهزة التابلت وأحجام الشاشات الكبيرة، مع دعم Android 5.0 فأحدث.
- إزالة الخلفية السوداء من شعار ELYAS-TECH داخل الواجهة.
- إزالة مربع حالة الترخيص من الصفحة الرئيسية مع بقاء صفحة الاشتراك في القائمة.
- بعد تسجيل الدفع يظهر خياران: طباعة الوصل أو حفظه كصورة PNG في ذاكرة الجهاز.
- إضافة زر حفظ للوصولات السابقة بجانب الطباعة.
- تغيير النص أسفل الشعار إلى رسالة ترحيبية تشرح فائدة التطبيق.
- تغيير أيقونة التطبيق إلى أيقونة مولدة كهربائية.
- لا تتغير سياسة الخصوصية: بيانات المشتركين والدفعات والوصولات تبقى محلياً، وSupabase للترخيص فقط.


## تحديث v0.4.2
- فصل تقرير حساب المشتركين عن المصروفات بالكامل؛ لم يعد التطبيق يحسب صافيًا بطرح مصروفات المولدة من اشتراكات المشتركين.
- عرض إجمالي اشتراكات المشتركين والمقبوض والمتبقي في قسم مستقل، وإجمالي مصروفات المولدة في قسم مستقل.
- حذف خيار تغيير رمز التفعيل من إعدادات تطبيق المستخدم. إدارة رمز التفعيل وتجديده تبقى من لوحة الإدارة فقط.


## تحديث v0.5.0 — Dark Green + مساعد المولدة الذكي
- تحويل واجهة التطبيق إلى هوية داكنة سوداء/خضراء مستوحاة من برنامج Mawldati Admin.
- بطاقات وأزرار وحدود تقنية حادة مع دعم الهاتف والتابلت.
- إضافة قسم **مساعد المولدة الذكي** يعمل محليًا بدون إنترنت للأسئلة الفنية العامة عن المولدات.
- يغطي المساعد: الحرارة، الدخان، الفولتية وAVR، RPM/Hz، الوقود، البطارية، الزيت، الصيانة، الأحمال والاهتزاز.
- إضافة حاسبة kVA → kW وحاسبة تيار ثلاثي الفاز.
- تجهيز اتصال اختياري بمساعد عبر الإنترنت من خلال API/Edge Function يحدده المستخدم؛ لا يتم إرسال بيانات المشتركين، وإنما السؤال المكتوب فقط.
- الحفاظ على Supabase للترخيص فقط، وجميع بيانات المشتركين والجباية والمصروفات والوصولات تبقى محليًا.
- تحديث الإصدار إلى 0.5.0.
